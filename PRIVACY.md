# Privacy Policy

**Last updated: September 30, 2026**

This Privacy Policy explains how the Rclone Backup Project ("the Project") handles information when you use or interact with the Project.

## 1. Overview

The Project is an open-source software project that allows users to create backups of their data to cloud storage services using Rclone and related technologies.

The Project is operated by an individual and is provided as open-source software.

## 2. Information We Collect

The Project does **not collect, store, or process personal information** from its users.

The Project does not operate user accounts, registration systems, analytics services, tracking systems, or advertising services.

We do not intentionally collect:

* Names or email addresses;
* IP addresses;
* Location information;
* Device or browser information;
* Usage or behavioral data;
* Backup contents;
* Files or other data stored in users' cloud accounts;
* Authentication credentials or access tokens.

## 3. Backup Data

The Project is designed to transfer users' data to cloud storage services selected and configured by the user.

The Project operator does not receive, access, store, or control the contents of users' backups.

Backup data is transferred directly between the user's systems and the cloud storage provider configured by the user, subject to the configuration and functionality of the software and the relevant cloud storage service.

Users are responsible for configuring their cloud storage accounts and access credentials appropriately.

## 4. Third-Party Services

The Project does not intentionally send personal information or backup data to third parties.

The Project itself does not use third-party analytics, advertising, tracking, or data-broker services.

However, the cloud storage provider selected by the user may independently collect and process information in accordance with its own privacy policy and terms of service.

Similarly, GitHub may process information when you visit or interact with the Project's GitHub repository. Such processing is governed by GitHub's own privacy practices and is outside the control of the Project.

## 5. Cookies and Tracking

The Project does not use cookies, web beacons, tracking pixels, analytics tools, or other tracking technologies.

The Project's GitHub repository may nevertheless be subject to cookies or similar technologies used by GitHub. Such technologies are controlled by GitHub and not by the Project.

## 6. Data Security

Because the Project does not collect or maintain personal information on its own servers, it does not maintain a separate database of user personal information.

Users are responsible for securing their own devices, cloud storage accounts, authentication credentials, and backup destinations.

## 7. Children's Privacy

The Project does not knowingly collect personal information from children or from any other users.

## 8. Changes to This Privacy Policy

This Privacy Policy may be updated from time to time to reflect changes to the Project or its practices.

Any changes will be published in this document, together with an updated "Last updated" date.

## 9. Contact

If you have questions about this Privacy Policy or the Project's privacy practices, please contact the Project maintainer through the contact information provided in the Project's GitHub repository.

---

**This Privacy Policy applies only to the Project and its own practices. It does not govern the privacy practices of GitHub, Rclone, or any cloud storage provider used with the Project.**
